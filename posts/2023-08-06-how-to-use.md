## 如何使用这个网站

> 2026 年 10 月更新：网站重新设计，构建与发布流程也已重写。本文随站点一起更新。

这是一个很小的网站。文章用 Markdown 写，页面由 `build.py` 生成，托管在 GitHub Pages 上。没有数据库，没有后台，也没有需要长期维护的框架。

## 写一篇新文章

在 `posts/` 目录下新建一个文件，文件名遵循：

`YYYY-MM-DD-slug.md`

文章的第一行写二级标题，它会成为页面标题：

```markdown
## 文章标题

正文从这里开始。
```

后面的内容就是普通 Markdown：段落、列表、引用、链接、图片、表格和代码块都可以直接使用。写完提交并推送到 GitHub，发布流程会自动运行。第一次使用时，需要在仓库的 **Settings → Pages** 中把发布来源设为 **GitHub Actions**。

也可以直接用写作工具创建，然后自动打开编辑器：

```bash
python new_post.py "文章的标题"
```

需要给文章加上作者和年份时：

```bash
python new_post.py "背影" --author 朱自清 --year 1925
```

## 本地预览

如果想把站点跑在自己的电脑上：

```bash
python -m pip install -r requirements.txt
python build.py --serve
```

然后打开 <http://127.0.0.1:8000/>。修改文章后重新运行 `build.py` 就能看到结果。

## 一些约定

- 标题必须使用 `##`，并且放在正文最前面。
- 日期和链接都来自文件名，所以发布后尽量不要改名。
- 需要调整站点标题、简介和作者信息，编辑根目录的 `site.json`。
- 原来的 `update.py` 已经被 `build.py` 取代。

这个网站会继续保持简单：写得舒服，读得安静，比功能多更重要。
